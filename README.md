# 医文课程跨校对照中的口径换版与补报

这是医学人文教学资料的本地分析工作区。各校提交的医文课程与学生修读事实，均为虚构演练资料。

## 资料

`data/school-submissions.csv` 是 UTF-8 编码的合成演练表。按学校、学生、培养方案和课程保留提交事实；映射与证据由使用者审定。

字段含义：学校、学生代号、方案版本、课程、课程类别、修读状态、活动、映射版本、证据引用。

表中代号只用于连接同一份演练资料，不对应真实人员、院校或患者。数据没有预先计算的统计结论。

## 运行

需要 Python 3.11 或更高版本，无第三方依赖。运行基线检查：

```sh
python3 -m unittest discover -s tests -v
```

`src/humanities_analytics/inputs.py` 提供通用 CSV 读取入口，将每行作为字符串字段返回。
